# NSCC Technical Domain — Recruitment Task Submission

Submission for the Newton School Coding Club (SRM IST) technical recruitment tasks. Both tasks live in their own folder below, each with its own README covering setup, features, and deployment.

## Structure

```
nscc-technical-tasks/
├── task1-signup-dashboard/     Task 1 — Signup form with validation and dashboard
└── task2-personal-intro/       Task 2 — Personal introduction page
```

## Tasks

- **[Task 1 — Signup Form with Validation and Dashboard](./task1-signup-dashboard)**
  A client-side signup form with regex-based validation, SHA-256 password hashing, localStorage persistence, a live dashboard table, and a delete button per account (brownie subtask).

- **[Task 2 — Personal Introduction Page](./task2-personal-intro)**
  A responsive personal introduction page styled as a series of terminal windows, with a dark/light mode toggle that persists across refreshes (brownie subtask).

Each folder's README has the full breakdown: how to run it, live deployment link, features implemented, and concepts used.
